# Contributing

Thanks for taking the time to improve Space Structures Lab.

## Before opening a pull request

1. Create a focused branch from `main`.
2. Install dependencies with `npm ci`.
3. Run `npm run build` and make sure it completes successfully.
4. Describe the change and include screenshots for user interface changes.

Keep pull requests focused, preserve the engineering assumptions documented
in `docs/STRUCTURAL_MODEL_ASSUMPTIONS.md`, and update the documentation when
behavior or limitations change.
